CAN Triple Device Manager

CAN Triple Device Manager configures the CAN Triple gateway — an STM32G473-based device with three CAN buses — over the ST-Link virtual COM port. You build a configuration as a document on the PC, then program it into the device in one explicit step.

How the program is organised

The application is offline-first: everything you edit lives in a configuration document (a .ct3 file), not in the device. Nothing reaches the hardware until you run Online → Send Configuration (F5), and the device's current configuration only enters the editor when you run Online → Get Configuration. This means you can prepare and validate a complete configuration at a desk with no hardware attached.

The status bar shows the document's file path on the left (or "Unsaved configuration"), and on the right the protected-comms state (only when the document carries a Protected Comms password) and the link state — "Connected: COM5 @ 7372800" or "Not connected".

Where to start

If this is your first session, read Getting Started: it walks from connecting the hardware to seeing live values.
